## 0.3.0 - 2026-11-27

Commit `88d718e3b18e`; release record `pub:sha2-256:s5ux3moknzr47jyz2ed7ug7tdp47txz6kgbymkw4aezhkz4xvuca`.

### Changed
- pubhost takes the hosting block's check, HOSTING_SEP and dnskey from pubrules.api, the surface pubrules holds steady, and needs pubrules 0.50.1 or later; tests/features/pubrules.feature fails on any import of pubrules from elsewhere

### Added
- pubhost terraform deletes and actions/terraform-deletes: fail a pull request that deletes Terraform resources without the terraform-destroy label
- terraform.yml's tf_vars names the calling repository's variables Terraform gets, each as TF_VAR_ and its lower-case name, whole however many lines it has; a name the repository has no variable of is left out

### Internal
- hosting.yml's terraform init runs through pubactions' actions/terraform-init (Sustenaut/pubactions v0.1.0), which pubrules 0.50.0 no longer ships, with pubrules.json's mirror.terraform read in a step before it and given as its mirror input; pubhost moves to pubrules 0.50.0
